# Progetto-GPO

 Funzionalità Principali

• Catalogo Eventi: Una bacheca digitale completa e navigabile dove esplorare tutti i volantini attivi, ordinati per popolarità, data o vicinanza.
• Acquista Biglietti: Integrazione diretta nei volantini per comprare ingressi o riservare posti in pochi clic, senza mai uscire dall'applicazione.
• Chatta con gli Organizzatori: Un canale di messaggistica istantanea per richiedere informazioni in tempo reale, prenotare tavoli o fare domande sullo specifico evento.
• Visualizza Profili: Pagine dedicate a locali, promoter o artisti per consultare lo storico dei loro eventi passati, vedere le recensioni e scoprire la programmazione futura.
